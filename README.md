# Career Compass

A single-page, eligibility-first career selector for students after Class 12.

## Run

Open `index.html` in a modern browser.

## Logic

1. The selected Class 12 stream acts as a hard eligibility gate.
2. Only eligible pathways are ranked.
3. Interest, preferred work style, course duration, entrance preference and priority affect the order.
4. Institution-specific eligibility must still be verified officially.
